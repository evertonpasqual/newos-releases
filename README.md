# NewOS · versões publicadas

Pacotes de atualização do NewOS (NewFront). Os servidores NewOS consultam
`latest.json` uma vez por dia e oferecem a atualização em
**Sistema › Atualizações**.

Cada pacote vem com `SHA256SUMS` assinado (ed25519) pela NewFront; o NewOS
recusa qualquer pacote sem assinatura válida. O código-fonte do NewOS não
fica neste repositório.
