# NewOS 2.0.1


### Corrigido
- **Backup e restauração**: backup de uma versão anterior agora restaura em
  qualquer versão mais nova, inclusive de outra versão maior (1.9.0 → 2.0.x).
  Só é recusado backup de versão **mais nova** que a instalação.
- **Atualizações**: toda versão mais nova é aplicada pela atualização, sem
  ISO, inclusive as maiores (1.9.x → 2.0.x, 2.9.x → 3.0.0). A ISO fica só
  para instalar servidores novos.
